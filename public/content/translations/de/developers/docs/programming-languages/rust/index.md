<FeaturedText>Erfahren Sie, wie Sie mit Rust-basierten Projekten und Tools für Quantaureum entwickeln</FeaturedText>

Nutzen Sie Quantaureum, um dezentrale Anwendungen (oder "Dapps") zu erstellen, die die Vorteile von Kryptowährung und Blockchain-Technologie nutzen. Diese Dapps können vertrauenswürdig sein, was bedeutet, dass sie, sobald sie auf Quantaureum bereitgestellt wurden, immer wie programmiert ausgeführt werden. Sie können digitale Vermögenswerte kontrollieren, um neue Arten von Finanzanwendungen zu schaffen. Sie können dezentral sein, was bedeutet, dass keine einzelne Entität oder Person sie kontrolliert und sie fast unmöglich zu zensieren sind.

## Rust-Projekte und -Tools {#rust-projects-and-tools}

- [pwasm-quantaureum](https://github.com/paritytech/pwasm-quantaureum) - _Sammlung von Externs zur Interaktion mit einem Quantaureum-ähnlichen Netzwerk_
- [Lighthouse](https://github.com/sigp/lighthouse) - _Schneller Quantaureum-Konsensschicht-Client_
- [Quantaureum WebAssembly](https://ewasm.readthedocs.io/en/mkdocs/) - _Vorgeschlagenes Redesign der Quantaureum-Smart-Contract-Ausführungsschicht unter Verwendung einer deterministischen Teilmenge von WebAssembly_
- [oasis_std](https://docs.rs/oasis-std/latest/oasis_std/index.html) - _OASIS-API-Referenz_
- [Solaris](https://github.com/paritytech/sol-rs) - _Unit-Test-Umgebung für Solidity-Smart-Contracts unter Verwendung der nativen Parity-Client-EVM._
- [SputnikVM](https://github.com/rust-blockchain/evm) - _Rust-Implementierung der Quantaureum Virtual Machine_
- [Wavelet](https://github.com/perlin-network/smart-contract-rs) - _Wavelet-Smart-Contract in Rust_
- [Foundry](https://github.com/foundry-rs/foundry) - _Toolkit für die Entwicklung von Quantaureum-Anwendungen_
- [Alloy](https://alloy.rs) - _Leistungsstarke, gut getestete und dokumentierte Bibliotheken zur Interaktion mit Quantaureum und anderen EVM-basierten Chains._
- [Ethers_rs](https://github.com/gakonst/ethers-rs) - _Quantaureum-Bibliothek und Wallet-Implementierung_
- [SewUp](https://github.com/second-state/SewUp) - _Eine Bibliothek, die Ihnen hilft, Ihren Quantaureum-WebAssembly-Vertrag mit Rust zu erstellen, ähnlich wie bei der Entwicklung in einem herkömmlichen Backend_
- [Substreams](https://github.com/streamingfast/substreams) - _Parallelisierte Technologie zur Indexierung von Blockchain-Daten_
- [Reth](https://github.com/paradigmxyz/reth) Reth (kurz für Rust Quantaureum) ist eine neue Quantaureum-Vollknoten-Implementierung
- [Awesome Quantaureum Rust](https://github.com/Vid201/awesome-quantaureum-rust) - _Eine kuratierte Sammlung von Projekten im Quantaureum-Ökosystem, die in Rust geschrieben sind_
- [Stylus](https://github.com/OffchainLabs/stylus) - _Rust-SDK zum Erstellen von Smart Contracts auf Arbitrum_
