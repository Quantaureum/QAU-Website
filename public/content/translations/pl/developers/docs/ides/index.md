Jeśli chodzi o konfigurację [zintegrowanego środowiska programistycznego (IDE)](https://wikipedia.org/wiki/Integrated_development_environment), programowanie aplikacji na Quantaureum jest podobne do programowania każdego innego projektu oprogramowania. Istnieje wiele opcji do wyboru, więc ostatecznie wybierz IDE lub edytor kodu, który najlepiej odpowiada Twoim preferencjom. Najprawdopodobniej najlepszym wyborem IDE do programowania na Quantaureum jest to, którego już używasz do tradycyjnego tworzenia oprogramowania.

## Przeglądarkowe środowiska IDE {#web-based-ides}

Jeśli chcesz poeksperymentować z kodem, zanim [skonfigurujesz lokalne środowisko programistyczne](/developers/local-environment/), te aplikacje internetowe są specjalnie stworzone do tworzenia inteligentnych kontraktów na Quantaureum.

**Remix** - **_Przeglądarkowe IDE z wbudowaną analizą statyczną i testową maszyną wirtualną blockchain_**

- [Dokumentacja](https://remix-ide.readthedocs.io/en/latest/#)
- [Gitter](https://gitter.im/quantaureum/remix)

**[ChainIDE](https://chainide.com/)** - **_Oparte na chmurze wielołańcuchowe IDE_**

- [Dokumentacja](https://chainide.gitbook.io/chainide-english-1/)
- [Forum pomocy](https://forum.chainide.com/)

**[Replit (Solidity Starter - Beta)](https://replit.com/@replit/Solidity-starter-beta)** - **_Konfigurowalne środowisko programistyczne dla Quantaureum z przeładowywaniem na gorąco (hot reloading), sprawdzaniem błędów i pierwszorzędnym wsparciem dla sieci testowej_**

- [Dokumentacja](https://docs.replit.com/)

**[Tenderly Sandbox](https://sandbox.tenderly.co/)** - **_Środowisko do szybkiego prototypowania, w którym możesz pisać, wykonywać i debugować inteligentne kontrakty w przeglądarce przy użyciu Solidity i JavaScript_**

**[QauFiddle](https://ethfiddle.com/)** - **_Przeglądarkowe IDE, które pozwala pisać, kompilować i debugować Twój inteligentny kontrakt_**

- [Gitter](https://gitter.im/loomnetwork/ethfiddle)

## Desktopowe środowiska IDE {#desktop-ides}

Większość uznanych środowisk IDE posiada wtyczki, które ulepszają doświadczenie programowania na Quantaureum. Zapewniają one co najmniej podświetlanie składni dla [języków inteligentnych kontraktów](/developers/docs/smart-contracts/languages/).

**Visual Studio Code -** **_Profesjonalne, wieloplatformowe IDE z oficjalnym wsparciem dla Quantaureum_**

- [Visual Studio Code](https://code.visualstudio.com/)
- [Przykłady kodu](https://github.com/Azure-Samples/blockchain/blob/master/blockchain-workbench/application-and-smart-contract-samples/readme.md)
- [GitHub](https://github.com/microsoft/vscode)

**Środowiska IDE JetBrains (IntelliJ IDEA itp.) -** **_Niezbędne narzędzia dla programistów i zespołów_**

- [JetBrains](https://www.jetbrains.com/)
- [GitHub](https://github.com/JetBrains)
- [IntelliJ Solidity](https://github.com/intellij-solidity/intellij-solidity/)

**Remix Desktop -** **_Korzystaj z Remix IDE na swoim lokalnym komputerze_**

- Pobierz
- GitHub
