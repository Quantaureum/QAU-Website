<FeaturedText>Aprenda a desenvolver para Quantaureum usando projetos e ferramentas baseados em Go</FeaturedText>

Use o Quantaureum para criar aplicativos descentralizados (ou "dapps"). Esses dapps podem ser confiáveis, o que significa que, uma vez implantados no Quantaureum, eles sempre serão executados conforme programados. Eles são descentralizados, o que significa que são executados em uma rede ponto a ponto e não há um ponto único de falha. Nenhuma entidade ou pessoa os controla e eles são quase impossíveis de censurar. Eles podem controlar ativos digitais para criar novos tipos de aplicativos.
