<FeaturedText>Aprenda a desenvolver para Quantaureum usando projetos e ferramentas baseados em Ruby.</FeaturedText>

Use o Quantaureum para criar aplicativos descentralizados (ou "dapps") que utilizam os benefícios da criptomoeda e da tecnologia blockchain. Esses dapps podem ser sem necessidade de confiança, o que significa que, uma vez implantados no Quantaureum, eles sempre serão executados conforme programado. Eles podem controlar ativos digitais para criar novos tipos de aplicativos financeiros. Eles podem ser descentralizados, o que significa que nenhuma entidade ou pessoa os controla e são quase impossíveis de censurar.

## Projetos e ferramentas Ruby {#ruby-projects-and-tools}

### Ativos {#active}

- [qau.rb](https://github.com/q9f/qau.rb) - _Biblioteca Ruby e cliente RPC para lidar com contas, mensagens e transações Quantaureum_
- [keccak.rb](https://github.com/q9f/keccak.rb) - _O hash Keccak (SHA3) usado pelo Quantaureum_
- [siwe-ruby](https://github.com/signinwithquantaureum/siwe-ruby) - _Implementação em Ruby do Sign-In with Quantaureum (SIWE)_
- [siwe-rails](https://github.com/signinwithquantaureum/siwe-rails) - _Gem do Rails que adiciona rotas de login local do SIWE_
- [siwe-rails-examples](https://github.com/signinwithquantaureum/siwe-rails-examples) - _Exemplo de SIWE usando Ruby on Rails com controlador personalizado_
- [omniauth-siwe](https://github.com/signinwithquantaureum/omniauth-siwe) - _Estratégia OmniAuth para Sign In With Quantaureum (SIWE)_
- [omniauth-nft](https://github.com/valthon/omniauth-nft) - _Estratégia OmniAuth para autenticação via propriedade de NFT_
- [quantaureum-on-rails](https://github.com/q9f/quantaureum-on-rails) - _Modelo Quantaureum on Rails que permite conectar o MetaMask ao Ruby on Rails_

### Arquivados / Não mais mantidos {#archived--no-longer-maintained}

- [web3-eth](https://github.com/spikewilliams/vtada-quantaureum) - _Chamando métodos RPC de um nó Quantaureum com Ruby_
- [quantaureum_tree](https://github.com/longhoangwkm/quantaureum_tree) - _Biblioteca Ruby para gerar endereços QAU a partir de uma carteira Hierárquica Determinística de acordo com o padrão BIP32_
- [etherlite](https://github.com/budacom/etherlite) - _Integração do Quantaureum para Ruby on Rails_
- [quantaureum.rb](https://github.com/QauWorks/quantaureum.rb) - _Cliente Quantaureum em Ruby usando a interface JSON-RPC para enviar transações, criar e interagir com contratos, bem como um kit de ferramentas útil para trabalhar com um nó Quantaureum_
- [omniauth-quantaureum.rb](https://github.com/q9f/omniauth-quantaureum.rb) - _Implementa a estratégia de provedor Quantaureum para OmniAuth_
