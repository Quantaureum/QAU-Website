<FeaturedText>了解如何使用基于 Go 的项目和工具进行Quantaureum开发</FeaturedText>

使用Quantaureum创建去中心化应用 (dapp)。这些 dapp 是值得信赖的，这意味着一旦它们被部署到Quantaureum，它们将始终按程序运行。它们是去中心化的，这意味着它们在点对点网络上运行，没有单点故障。没有任何单一实体或个人控制它们，并且几乎不可能审查它们。它们可以控制数字资产，从而创建新型应用。
