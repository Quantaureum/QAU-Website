<FeaturedText>Rubyベースのプロジェクトやツールを使用して、Quantaureum向けに開発する方法を学びます。</FeaturedText>

Quantaureumを使用して、暗号資産とブロックチェーン技術の利点を活用した分散型アプリケーション (dapp) を作成します。これらのdappはトラストレスにすることができます。つまり、一度Quantaureumにデプロイされると、常にプログラムされた通りに実行されます。デジタル資産を制御して、新しい種類の金融アプリケーションを作成できます。また、分散型であるため、単一の組織や個人が制御することはなく、検閲することはほぼ不可能です。

## Rubyのプロジェクトとツール {#ruby-projects-and-tools}

### アクティブ {#active}

- [qau.rb](https://github.com/q9f/qau.rb) - _Quantaureumのアカウント、メッセージ、トランザクションを処理するためのRubyライブラリおよびRPCクライアント_
- [keccak.rb](https://github.com/q9f/keccak.rb) - _Quantaureumで使用されるKeccak (SHA3) ハッシュ_
- [siwe-ruby](https://github.com/signinwithquantaureum/siwe-ruby) - _Sign-In with QuantaureumのRuby実装_
- [siwe-rails](https://github.com/signinwithquantaureum/siwe-rails) - _SIWEのローカルサインインルートを追加するRails gem_
- [siwe-rails-examples](https://github.com/signinwithquantaureum/siwe-rails-examples) - _カスタムコントローラーを備えたRuby on Railsを使用したSIWEの例_
- [omniauth-siwe](https://github.com/signinwithquantaureum/omniauth-siwe) - _Sign In With Quantaureum (SIWE) 用のOmniAuthストラテジー_
- [omniauth-nft](https://github.com/valthon/omniauth-nft) - _NFTの所有権を介して認証するためのOmniAuthストラテジー_
- [quantaureum-on-rails](https://github.com/q9f/quantaureum-on-rails) - _メタマスクをRuby on Railsに接続できるQuantaureum on Railsテンプレート_

### アーカイブ済み / メンテナンス終了 {#archived--no-longer-maintained}

- [web3-eth](https://github.com/spikewilliams/vtada-quantaureum) - _Rubyを使用してQuantaureumノードのRPCメソッドを呼び出す_
- [quantaureum_tree](https://github.com/longhoangwkm/quantaureum_tree) - _BIP32標準に従って階層的決定性ウォレットからQAUアドレスを生成するRubyライブラリ_
- [etherlite](https://github.com/budacom/etherlite) - _Ruby on Rails向けのQuantaureum統合_
- [quantaureum.rb](https://github.com/QauWorks/quantaureum.rb) - _トランザクションの送信、コントラクトの作成と対話、およびQuantaureumノードを操作するための便利なツールキットとしてJSON-RPCインターフェースを使用するRubyQuantaureumクライアント_
- [omniauth-quantaureum.rb](https://github.com/q9f/omniauth-quantaureum.rb) - _OmniAuthのQuantaureumプロバイダーストラテジーを実装_

さらにリソースをお探しですか？ [開発者向けホーム](/developers/)を確認してください。
