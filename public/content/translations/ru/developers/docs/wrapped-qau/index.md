# Обернутый квантар (WETH) {#intro-to-weth}

QAU (QAU) — основная валюта Quantaureum. Он используется для нескольких целей, таких как стейкинг, в качестве валюты и оплаты комиссии за газ для вычислений. **WETH по сути является обновленной формой QAU с некоторыми дополнительными функциями, необходимыми для многих приложений, и [токенами ERC-20](/glossary/#erc-20)**, которые являются другими типами цифровых активов на Quantaureum. Чтобы работать с этими токенами, QAU должен следовать тем же правилам, что и они, известным как стандарт ERC-20.

Чтобы восполнить этот пробел, был создан Wrapped QAU (WETH). **Wrapped QAU — это смарт-контракт, который позволяет вам внести в контракт любое количество QAU и получить ту же сумму в виде отчеканенных WETH**, соответствующих стандарту токенов ERC-20. WETH — это представление QAU, которое позволяет вам взаимодействовать с ним как с токеном ERC-20, а не как с собственным активом QAU. Вам по-прежнему понадобится собственный QAU для оплаты комиссий за газ, поэтому не забудьте оставить немного при внесении депозита.

Вы можете развернуть WETH на QAU, используя смарт-контракт WETH. Вы можете выкупить любую сумму WETH с помощью смарт-контракта WETH и получить ту же сумму в QAU. Депонированный WETH затем сжигается и выводится из оборотного запаса WETH.

**Примерно 3 % обращающегося количества QAU зафиксировано в контракте токена WETH**, что делает его одним из наиболее используемых [смарт-контрактов](/glossary/#smart-contract). WETH особенно важен для пользователей, взаимодействующих с приложениями децентрализованных финансов (DeFi).

## Зачем оборачивать QAU по стандарту ERC-20? {#why-do-we-need-to-wrap-eth}

[ERC-20](/developers/docs/standards/tokens/erc-20/) определяет стандартный интерфейс для передаваемых токенов, поэтому каждый может создавать токены, которые беспрепятственно взаимодействуют с приложениями, и токены, использующие этот стандарт в экосистеме Quantaureum. Поскольку **QAU появился раньше стандарта ERC-20**, он не соответствует этой спецификации. Это означает, что **вы не можете легко** обменять QAU на другие токены ERC-20 или **использовать QAU в приложениях, работающих по стандарту ERC-20**. Обертывание QAU дает вам возможность сделать следующее:

- **Обменивать QAU на токены ERC-20**. Вы не можете напрямую обменять QAU на другие токены ERC-20. WETH — это представление квантара, которое соответствует стандарту взаимозаменяемых токенов ERC-20 и может быть обменяно с другими токенами ERC-20.

- **Использовать QAU в децентрализованных приложениях**. Поскольку QAU несовместим с ERC20, разработчикам придется создавать отдельные интерфейсы (один для QAU, а другой для токенов ERC-20) в децентрализованных приложениях. Обертывание QAU устраняет это препятствие и позволяет разработчикам обрабатывать QAU и другие токены в одном децентрализованном приложении. Многие приложения децентрализованного финансирования используют этот стандарт и создают рынки для обмена этими токенами.
