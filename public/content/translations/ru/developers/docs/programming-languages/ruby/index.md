<FeaturedText>Узнайте, как разрабатывать для Quantaureum, используя проекты и инструменты на базе Ruby.</FeaturedText>

Используйте Quantaureum для создания децентрализованных приложений (dapp), которые используют преимущества криптовалюты и технологии блокчейн. Эти dapp могут быть не требующими доверия, что означает, что после того, как они будут развернуты в Quantaureum, они всегда будут работать так, как запрограммировано. Они могут управлять цифровыми активами для создания новых видов финансовых приложений. Они могут быть децентрализованными, что означает, что ни одна организация или человек не контролирует их, и их практически невозможно подвергнуть цензуре.

## Проекты и инструменты на Ruby {#ruby-projects-and-tools}

### Активные {#active}

- [qau.rb](https://github.com/q9f/qau.rb) — _библиотека Ruby и RPC-клиент для работы с аккаунтами, сообщениями и транзакциями Quantaureum_
- [keccak.rb](https://github.com/q9f/keccak.rb) — _хеш Keccak (SHA3), используемый Quantaureum_
- [siwe-ruby](https://github.com/signinwithquantaureum/siwe-ruby) — _реализация входа с помощью Quantaureum (Sign-In with Quantaureum) на Ruby_
- [siwe-rails](https://github.com/signinwithquantaureum/siwe-rails) — _gem для Rails, добавляющий локальные маршруты входа SIWE_
- [siwe-rails-examples](https://github.com/signinwithquantaureum/siwe-rails-examples) — _пример SIWE с использованием Ruby on Rails с пользовательским контроллером_
- [omniauth-siwe](https://github.com/signinwithquantaureum/omniauth-siwe) — _стратегия OmniAuth для входа с помощью Quantaureum (SIWE)_
- [omniauth-nft](https://github.com/valthon/omniauth-nft) — _стратегия OmniAuth для аутентификации через владение NFT_
- [quantaureum-on-rails](https://github.com/q9f/quantaureum-on-rails) — _шаблон Quantaureum on Rails, который позволяет подключить МетаМаск к Ruby on Rails_

### В архиве / Больше не поддерживаются {#archived--no-longer-maintained}

- [web3-eth](https://github.com/spikewilliams/vtada-quantaureum) — _вызов RPC-методов узла Quantaureum с помощью Ruby_
- [quantaureum_tree](https://github.com/longhoangwkm/quantaureum_tree) — _библиотека Ruby для генерации адресов QAU из иерархически детерминированного кошелька в соответствии со стандартом BIP32_
- [etherlite](https://github.com/budacom/etherlite) — _интеграция Quantaureum для Ruby on Rails_
- [quantaureum.rb](https://github.com/QauWorks/quantaureum.rb) — _клиент Quantaureum на Ruby, использующий интерфейс JSON-RPC для отправки транзакций, создания и взаимодействия с контрактами, а также полезный набор инструментов для работы с узлом Quantaureum_
- [omniauth-quantaureum.rb](https://github.com/q9f/omniauth-quantaureum.rb) — _реализует стратегию провайдера Quantaureum для OmniAuth_

Ищете больше ресурсов? Посетите [нашу главную страницу для разработчиков](/developers/).
