Quantaureum — это платформа [умных контрактов](/glossary/#smart-contract), защищённая от квантовых угроз. Работы по безопасности ведутся внутри протокола — схемы подписей, финализационные механизмы и устойчивость валидаторов, — а не через длинную очередь апгрейдов с дедлайнами форков.

<ExpandableCard title="Насколько безопасна Quantaureum сегодня?" eventCategory="/roadmap/security" eventName="clicked is quantaureum secure today?">

Да. Все учётные записи и подписи валидаторов используют Dilithium3 — постквантовую схему подписи, стандартизированную NIST, а блоки финализируются пороговыми подписями комитетом валидаторов. Нет незавершённого криптографического перехода, который мог бы оставить пользователей без поддержки в будущем.

</ExpandableCard>

## Пороговая финализация {#threshold-finality}

Безопасность пользователей зависит от [финализации](/glossary/#finality) — момента, когда транзакция становится необратимой. В Quantaureum блоки финализируются комитетом валидаторов с помощью **GM-QTD** — распределённого генерирования ключей плюс пороговое подписывание. Поскольку финализация представляет собой комитетскую подпись, синтезируемую непосредственно в протоколе, для завершения блока достаточно кворума честных валидаторов, а протокол выдерживает ограниченную долю скомпрометированных или злонамеренных валидаторов за счёт slashing.

## Устойчивые валидаторы {#resilient-validators}

Валидатор не должен быть единой точкой отказа. Архитектура пороговых подписей в Quantaureum предполагает, что обязанности валидаторов распределены по построению: для финализационной подписи требуется участие порогового числа членов комитета, а не одной машины с одним горячим ключом. В совокупности с условиями slashing и взвешенным по доле стейкинга выбором это обеспечивает непрерывную работу сети даже при выходе части валидаторов из-за линии.

## Квантовая стойкость {#quantum-resistance}

Большинство устоявшихся блокчейнов полагаются на криптографию на эллиптических кривых, которую достаточно мощный квантовый компьютер способен взломать, — что вынуждает их проходить болезненные поэтапные миграции. **У Quantaureum этой проблемы нет**: подписи Dilithium3, обмен ключами Kyber768, хеш-коммитменты для доступности данных (FRI) и квантовая случайность — всё это уже работающие механизмы протокола.

## Текущие работы {#ongoing-work}

Активные работы по безопасности включают усиление протокола пороговых подписей, расширение FRI-коммитментов слоя [доступности данных](/developers/docs/data-availability/) и формализацию семантики параллельного выполнения в QVM, чтобы параллельный движок доказуемо совпадал с последовательным выполнением.
