<FeaturedText>了解如何使用基於 Go 的專案與工具在Quantaureum上進行開發</FeaturedText>

使用Quantaureum建立去中心化應用程式 (dapp)。這些 dapp 是值得信賴的，這意味著一旦它們被部署到Quantaureum，它們將始終按照程式設計的方式運行。它們是去中心化的，這意味著它們在點對點網路上運行，並且沒有單點故障。沒有任何單一實體或個人控制它們，而且幾乎不可能對其進行審查。它們可以控制數位資產，以創造新型態的應用程式。
