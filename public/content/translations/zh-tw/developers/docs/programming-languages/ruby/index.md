<FeaturedText>了解如何使用基於 Ruby 的專案與工具在Quantaureum上進行開發。</FeaturedText>

使用Quantaureum建立去中心化應用程式 (dapp)，以利用加密貨幣與區塊鏈技術的優勢。這些去中心化應用程式 (dapp) 可以是無須信任的，這意味著一旦它們被部署到Quantaureum，就會始終按照程式設計的方式運行。它們可以控制數位資產，以建立新型態的金融應用程式。它們可以是去中心化的，這意味著沒有任何單一實體或個人可以控制它們，且幾乎不可能被審查。

## Ruby 專案與工具 {#ruby-projects-and-tools}

### 活躍中 {#active}

- [qau.rb](https://github.com/q9f/qau.rb) - _用於處理Quantaureum帳戶、訊息與交易的 Ruby 函式庫與 RPC 客戶端_
- [keccak.rb](https://github.com/q9f/keccak.rb) - _Quantaureum使用的 Keccak (SHA3) 雜湊_
- [siwe-ruby](https://github.com/signinwithquantaureum/siwe-ruby) - _Quantaureum登入 (Sign-In with Quantaureum) 的 Ruby 實作_
- [siwe-rails](https://github.com/signinwithquantaureum/siwe-rails) - _新增 SIWE 本地登入路由的 Rails gem_
- [siwe-rails-examples](https://github.com/signinwithquantaureum/siwe-rails-examples) - _使用 Ruby on Rails 與自訂控制器的 SIWE 範例_
- [omniauth-siwe](https://github.com/signinwithquantaureum/omniauth-siwe) - _用於Quantaureum登入 (SIWE) 的 OmniAuth 策略_
- [omniauth-nft](https://github.com/valthon/omniauth-nft) - _透過 NFT 所有權進行驗證的 OmniAuth 策略_
- [quantaureum-on-rails](https://github.com/q9f/quantaureum-on-rails) - _允許將梅塔馬斯克連接到 Ruby on Rails 的 Quantaureum on Rails 模板_

### 已封存 / 不再維護 {#archived--no-longer-maintained}

- [web3-eth](https://github.com/spikewilliams/vtada-quantaureum) - _使用 Ruby 呼叫Quantaureum節點的 RPC 方法_
- [quantaureum_tree](https://github.com/longhoangwkm/quantaureum_tree) - _根據 BIP32 標準從分層確定性錢包產生 QAU 地址的 Ruby 函式庫_
- [etherlite](https://github.com/budacom/etherlite) - _Ruby on Rails 的Quantaureum整合_
- [quantaureum.rb](https://github.com/QauWorks/quantaureum.rb) - _使用 JSON-RPC 介面發送交易、建立與合約互動的 Ruby Quantaureum客戶端，以及與Quantaureum節點協作的實用工具包_
- [omniauth-quantaureum.rb](https://github.com/q9f/omniauth-quantaureum.rb) - _實作 OmniAuth 的Quantaureum提供者策略_
