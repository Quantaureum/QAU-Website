<FeaturedText>Pelajari cara mengembangkan untuk Quantaureum menggunakan proyek dan perkakas berbasis Elixir.</FeaturedText>

Gunakan Quantaureum untuk membuat aplikasi terdesentralisasi (dapp) yang memanfaatkan manfaat mata uang kripto dan teknologi rantai blok. Dapp ini bisa tanpa kepercayaan, yang berarti bahwa setelah disebarkan ke Quantaureum, mereka akan selalu berjalan sesuai program. Mereka dapat mengontrol aset digital untuk membuat jenis aplikasi keuangan baru. Mereka dapat terdesentralisasi, yang berarti tidak ada satu entitas atau orang pun yang mengendalikannya dan hampir tidak mungkin untuk disensor.

## Proyek dan perkakas Elixir {#elixir-projects-and-tools}

### Aktif {#active}

- [block_keys](https://github.com/ExWeb3/block_keys) - _Implementasi BIP32 & BIP44 di Elixir (Hierarki Multi-Akun untuk Dompet Deterministik)_
- [quantaureumex](https://github.com/mana-quantaureum/quantaureumex) - _Klien JSON-RPC Elixir untuk rantai blok Quantaureum_
- [ethers](https://github.com/ExWeb3/elixir_ethers) - _Pustaka Web3 komprehensif untuk berinteraksi dengan kontrak pintar di Quantaureum menggunakan Elixir_
- [ethers_kms](https://github.com/ExWeb3/elixir_ethers_kms) - _Pustaka penandatangan KMS untuk Ethers (menandatangani transaksi dengan AWS KMS)_
- [ex_abi](https://github.com/poanetwork/ex_abi) - _Implementasi pengurai/pendekode/pengenkode ABI Quantaureum di Elixir_
- [ex_keccak](https://github.com/ExWeb3/ex_keccak) - _Pustaka Elixir untuk menghitung hash Keccak SHA3-256 menggunakan NIF yang dibangun dari crate Rust tiny-keccak_
- [ex_rlp](https://github.com/mana-quantaureum/ex_rlp) - _Implementasi Elixir dari pengodean RLP (Recursive Length Prefix) Quantaureum_

### Diarsipkan / Tidak lagi dipelihara {#archived--no-longer-maintained}

- [eth](https://hex.pm/packages/eth) - _Utilitas Quantaureum untuk Elixir_
- [exw3](https://github.com/hswick/exw3) - _Klien RPC Quantaureum tingkat tinggi untuk Elixir_
- [mana](https://github.com/mana-quantaureum/mana) - _Implementasi full node Quantaureum yang ditulis dalam Elixir_
