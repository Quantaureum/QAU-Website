This is the repo for [quantaureum.com](https://quantaureum.com), the official website of Quantaureum — a quantum-safe blockchain powered by post-quantum cryptography (ML-DSA / Dilithium3 and ML-KEM / Kyber), the QPOS consensus protocol, Stardust three-chamber governance, and GM-QTD threshold signatures.

The site's purpose is to be the best portal to Quantaureum for our growing global community.

## Looking for the Quantaureum node implementation?

The Quantaureum protocol itself lives in a separate repository. Head over to the [Quantaureum GitHub organization](https://github.com/Quantaureum) to find the node implementation and related tooling.

## How to contribute

Before you start, please take a moment to read our [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

### 1. Submit an issue

- Create a [new issue](https://github.com/Quantaureum/QAU-Website/issues).
- Comment on the issue if you'd like to be assigned to it.

### 2. Fork the repository

Fork the repo, create a branch, and open a pull request against `master`.

### 3. Set up your local environment

We recommend using **Node.js** (see `.nvmrc`) and **pnpm**:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

More details can be found in [docs/stack.md](docs/stack.md) and [docs/best-practices.md](docs/best-practices.md).
